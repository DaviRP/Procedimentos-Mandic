    Como funciona

    1. Cada orçamento vira um plano por perfil de tratamento.
    2. Itens convertidos com certeza vão para A integrar.
    3. Casos ambíguos vão para Revisar; itens sem procedimento, para Sem equivalência.
    4. Orçamentos que já estão no banco para a mesma clínica são ignorados.
